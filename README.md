# Elixir

A cinematic, story-driven portfolio and showcase platform built with Next.js 16, React 19, Tailwind CSS v4, GSAP ScrollTrigger, and Lenis smooth scrolling.

## 🚀 Highlights & Features

- **Storytelling Hero Canvas:** Seamless 60FPS video hero section with vignette and smooth transition curves.
- **Cinematic Dolly-In Push ("What You'll Receive"):** 72-frame high-performance canvas scrub with match-cut infinite zoom into the iMac display.
- **Interactive Discrete Cards:** 3D perspective cards with zero overlap, progressive elevation, and fluid layout pacing.
- **Projects Showcase & 3D Parallax:** Production apps grid featuring 1-by-1 entrance from bottom with inner image parallax and category filtering.
- **Live Supabase Realtime Integration:** Project showcase syncs with Supabase PostgreSQL in real-time.
- **Web3Forms Contact Form:** Direct email delivery and instant WhatsApp redirect.
- **Fully Responsive & Touch-Optimized:** Calibrated for mobile (320px–640px), tablet (768px–1024px), and ultra-wide desktops.
- **Lenis Inertial Physics Scrolling:** Synced with GSAP tickers for buttery-smooth mouse wheel and touch navigation.

## 🛠️ Tech Stack

- **Framework:** [Next.js 16 (App Router)](https://nextjs.org/)
- **UI & Components:** [React 19](https://react.dev/), [Lucide React](https://lucide.dev/)
- **Styling:** [Tailwind CSS v4](https://tailwindcss.com/)
- **Animations:** [GSAP (ScrollTrigger)](https://gsap.com/), [Lenis](https://lenis.darkroom.engineering/)
- **Backend & Database:** [Supabase](https://supabase.com/)
- **Contact API:** [Web3Forms](https://web3forms.com/)

## 📦 Getting Started

### Prerequisites

- Node.js 18+ installed

### Installation

```bash
# Clone the repository
git clone https://github.com/Mahs-X/Elixir.git
cd Elixir

# Install dependencies
npm install

# Run the development server
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) with your browser to see the result.
